# Wordleaf Releases

This repository distributes public Wordleaf installer assets and release metadata. The application source is maintained separately in a private repository.

The currently published Windows installer is available under the latest GitHub Release. `installers.json` points to the actual published Windows installer and its verified SHA-256 checksum. A Mac installer and signed automatic-update manifest must only be added after successfully building, signing, and verifying those assets. Never publish the private application source or editable document projects here.
